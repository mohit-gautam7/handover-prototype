Demo guide

Each scenario takes under a minute. All views share the same data, so you can follow one case from report to handover.

  1. Report a child left alone

    Meera reports her nephew Aarav, 3. Watch the priority change as you edit the answers.

  2. Report by text message

    The same report as an SMS conversation for basic phones.

  3. Hand over as a responder

    Accept Aarav (or Riya), pick a partner, check the code, hand over.

  4. Be the stand-in

    See the code, the care card and the 72-hour check-in.

  5. Change a priority

    As coordinator, raise Kabir’s case with a reason. The family is told.

  6. Do a phone check

    Confirm the adult with Mrs D’Souza, or turn it into a visit.

  7. Watch cases escalate

    Move the clock forward two hours. Cases with no contact for 12 hours move up a level.

  8. Report with no network

    The report waits on the phone and sends itself when the network returns.

  9. Read the metrics

    Safe-within-window rate, detection, speed, durability and safety, plus the hour-by-hour chart.

  10. See the live map

    Cases and responders by ward. Pins never show an address.

  11. Simulate a surge

    Five new reports arrive by web, SMS and police. Watch the triage and the live activity feed.

  12. The stand-in says no

    From the stand-in’s phone. The code is cancelled and the family is asked to name someone else.

  13. The responder can’t make it

    Release a case with a reason. It goes back to the queue and the family is told.
